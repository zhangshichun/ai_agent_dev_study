# 代码审查助手

这个技能帮助用户审查代码质量，提供改进建议。

## 适用场景

- 用户想要审查代码
- 用户想要优化代码结构
- 用户想要检查代码规范

## 命令

- `/review`: 审查代码
- `/suggest`: 提供改进建议
- `/check-style`: 检查代码风格

## 审查标准

### 1. 代码可读性

变量命名是否清晰？函数是否过长？

### 2. 性能考虑

是否有不必要的循环？是否需要缓存？

### 3. 安全检查

是否有 SQL 注入风险？是否有 XSS 漏洞？
